# Radius

| Variable | Radius | Class      |
| -------- | ------ | ---------- |
| sm       | 4px    | rounded-sm |
| md       | 8px    | rounded-md |
| lg       | 12px   | rounded-lg |
| xl       | 16px   | rounded-xl |

## Styles

```css
--radius: 0.75rem;

--radius-sm: calc(var(--radius) - 8px); /*4px*/
--radius-md: calc(var(--radius) - 4px); /*8px*/
--radius-lg: var(--radius); /*12px*/
--radius-xl: calc(var(--radius) + 4px); /*16px*/
```
