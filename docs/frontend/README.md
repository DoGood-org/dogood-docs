# Документація Frontend

Ласкаво просимо до документації фронтенд-частини проєкту.

Тут зібрані правила розробки, структура проєкту, дизайн-система та документація перевикористовуваних компонентів.

## Зміст

### UI-компоненти

Опис перевикористовуваних UI-компонентів, їх API, приклади використання та особливості реалізації.

---

### Стилі

Документація дизайн-системи проєкту.

Містить:

* брейкпоінти;
* кольори;
* текстові стилі;
* радіуси;
* інші дизайн-токени.

---

### Іконки

Інструкція по роботі з SVG-іконками.

Містить:

* додавання нових іконок;
* використання іконок у компонентах;
* стилізацію іконок.

---

### Структура проєкту

Опис структури директорій та призначення основних папок проєкту.

Містить:

* структуру папок;
* призначення директорій;
* рекомендації щодо розміщення файлів.

---

### Правила розробки

Загальні правила написання фронтенд-коду.

Містить:

* правила найменування;
* правила створення компонентів;
* вимоги до сторінок;
* рекомендації щодо архітектури;
* правила встановлення бібліотек.

---

### Робота з Git

Правила роботи з репозиторієм та процес розробки.

Містить:

* робочі гілки;
* правила створення Pull Request;
* процес злиття змін;
* вимоги до тестування перед мерджем.
