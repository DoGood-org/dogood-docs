# POST /organization/members

## Призначення

Надсилає користувачу запрошення приєднатися до організації.

> [!NOTE]
> - Цей endpoint **не створює** запис `UserOrganization`.
>
> - Він створює **JoinRequest** з напрямком `FROM_ORGANIZATION`.
>
> - Членство буде створене лише після прийняття запрошення.

---

## Авторизація

✅ Потрібна

Користувач повинен бути авторизований.

---

## Request Body

| Поле           | Тип              | Обов'язкове | Опис                                                 |
| -------------- | ---------------- | :---------: | ---------------------------------------------------- |
| userId         | string           |      ✔      | ID користувача                                       |
| organizationId | string           |      ✔      | ID організації                                       |
| role           | OrganizationRole |      ✔      | Роль, яка буде призначена після прийняття запрошення |

> Дозволені значення `role`:
>
> - MEMBER
> - MODERATOR

---

## Business Rules

- користувач повинен бути членом організації;
- лише `ADMIN` та `MODERATOR` можуть запрошувати нових користувачів;
- `MODERATOR` не може запросити користувача з роллю `ADMIN`;
- користувача не можна запросити повторно, якщо він уже є членом організації;
- endpoint створює `JoinRequest`, а не `UserOrganization`;
- запрошеному користувачу створюється Notification.

---

## Що робить бекенд

1. Перевіряє авторизацію користувача.
2. Перевіряє членство через `requireMembership()`.
3. Перевіряє роль (`ADMIN` або `MODERATOR`).
4. Перевіряє, що `MODERATOR` не запрошує `ADMIN`.
5. Перевіряє, що користувач ще не є членом організації (`findMembership()`).
6. Створює `JoinRequest`.
7. Створює Notification.
8. Повертає створений JoinRequest.

---

```json
  "message": "Invitation has been sent to the user",
  "data": {
    "invite": {
      "...": "..."
    }
  }
}
```

---

## Побічні ефекти

Після успішного виконання:

- створюється запис `JoinRequest`;
- користувачу створюється Notification;
- запис `UserOrganization` **ще не створюється**.

---

## ❌ Помилки

| Код                                | HTTP | Опис                                                                         |
| ---------------------------------- | ---- | ---------------------------------------------------------------------------- |
| AUTH_UNAUTHORIZED                  | 401  | Користувач не авторизований                                                  |
| USER_IS_NOT_MEMBER_OF_ORGANIZATION | 404  | Поточний користувач (від якого надходить запрошення) не є членом організації |
| MEMBBER_DONT_HAVE_PERMISSION       | 403  | Недостатньо прав                                                             |
| USER_ALREADY_MEMBER                | 409  | Користувач уже є членом організації                                          |
