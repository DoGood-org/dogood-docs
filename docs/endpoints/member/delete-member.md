# DELETE /organization/members

## Призначення

Видаляє користувача з організації.

Після успішного виконання запис **UserOrganization** видаляється з бази даних, а користувач втрачає членство в організації.

---

## Авторизація

✅ Потрібна

Користувач повинен бути авторизований.

---

## Request Body

| Поле           | Тип    | Обов'язкове | Опис                                     |
| -------------- | ------ | :---------: | ---------------------------------------- |
| userId         | string |      ✔      | ID користувача, якого необхідно видалити |
| organizationId | string |      ✔      | ID організації                           |

---

## Business Rules

- організація повинна існувати;
- користувач, який виконує запит, повинен бути членом організації;
- видаляти учасників можуть лише користувачі з ролями **ADMIN** або **MODERATOR**;
- користувач, якого видаляють, повинен бути членом організації;
- після успішного видалення користувачу створюється Notification типу `ORG_MEMBER_REMOVED`.

---

## Що робить бекенд

1. Перевіряє наявність `userId` та `organizationId`.
2. Перевіряє існування організації.
3. Визначає поточного авторизованого користувача.
4. Перевіряє його членство в організації через `requireMembership()`.
5. Перевіряє, що поточний користувач має роль `ADMIN` або `MODERATOR`.
6. Перевіряє, що користувач, якого потрібно видалити, є членом організації (`requireMembership()` у сервісі).
7. Видаляє запис `UserOrganization`.
8. Створює Notification типу `ORG_MEMBER_REMOVED`.
9. Повертає повідомлення про успішне видалення.

---

## Response

```json
{
  "status": "success",
  "code": "MEMBER_REMOVED_FROM_ORGANIZATION",
  "message": "Member removed from organization"
}
```

---

## Побічні ефекти

Після успішного виконання endpoint:

- запис **UserOrganization** видаляється з бази даних;
- користувач більше не є членом організації;
- користувачу створюється Notification типу `ORG_MEMBER_REMOVED`.

---

## ❌ Помилки

| Код                                | HTTP | Опис                                    |
| ---------------------------------- | ---- | --------------------------------------- |
| USER_ID_OR_ORGANIZATION_ID_INVALID | 400  | Відсутній `userId` або `organizationId` |
| AUTH_UNAUTHORIZED                  | 401  | Користувач не авторизований             |
| MEMBBER_DONT_HAVE_PERMISSION       | 403  | Недостатньо прав для видалення учасника |
| ORGANIZATION_NOT_FOUND             | 404  | Організацію не знайдено                 |
| USER_IS_NOT_MEMBER_OF_ORGANIZATION | 404  | Користувач не є членом організації      |
