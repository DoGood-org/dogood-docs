# PATCH /organization/members/role

## Призначення

Змінює роль учасника організації.

Endpoint оновлює роль існуючого запису **UserOrganization** та повідомляє користувача про зміну ролі.

---

## Авторизація

✅ Потрібна

Користувач повинен бути авторизований.

---

## Request Body

| Поле           | Тип              | Обов'язкове | Опис                                        |
| -------------- | ---------------- | :---------: | ------------------------------------------- |
| organizationId | string           |      ✔      | ID організації                              |
| userId         | string           |      ✔      | ID користувача, роль якого потрібно змінити |
| role           | OrganizationRole |      ✔      | Нова роль користувача                       |

> Дозволені значення `role`:
>
> - MEMBER
> - MODERATOR

---

## Business Rules

- користувач повинен бути авторизований;
- користувач, який виконує запит, повинен бути членом організації;
- змінювати ролі може лише користувач із роллю **ADMIN**;
- нова роль може бути лише `MEMBER` або `MODERATOR`;
- після успішної зміни ролі користувачу створюється Notification типу `ORG_ROLE_UPDATED`.

---

## Що робить бекенд

1. Перевіряє авторизацію користувача.
2. Перевіряє членство користувача через `requireMembership()`.
3. Перевіряє, що користувач має роль `ADMIN`.
4. Перевіряє коректність переданої ролі.
5. Оновлює поле `role` у записі `UserOrganization`.
6. Створює Notification типу `ORG_ROLE_UPDATED`.
7. Повертає оновлений запис членства.

## Побічні ефекти

Після успішного виконання endpoint:

- у таблиці **UserOrganization** оновлюється поле `role`;
- користувачу створюється Notification типу `ORG_ROLE_UPDATED`.

## ❌ Помилки

| Код                                | HTTP | Опис                                        |
| ---------------------------------- | ---- | ------------------------------------------- |
| MEMBER_ROLE_INVALID                | 400  | Передано недопустиме значення ролі          |
| AUTH_UNAUTHORIZED                  | 401  | Користувач не авторизований                 |
| MEMBBER_DONT_HAVE_PERMISSION       | 403  | Недостатньо прав для зміни ролі             |
| USER_IS_NOT_MEMBER_OF_ORGANIZATION | 404  | Поточний користувач не є членом організації |
