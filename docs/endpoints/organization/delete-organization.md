# DELETE /organization/:id

## Призначення

Видаляє організацію та всі пов'язані з нею дані.

Видалення доступне лише користувачу з роллю `ADMIN` цієї організації.

> [!WARNING]
>
> Це незворотна операція.
>
> Разом з організацією видаляються всі пов'язані записи.

---

## Авторизація

✅ Потрібна

Користувач повинен бути авторизований.

---

## Path Parameters

| Параметр | Тип    | Обов'язковий | Опис           |
| -------- | ------ | :----------: | -------------- |
| id       | string |      ✔       | ID організації |

---

## Business Rules

- користувач повинен бути авторизований;
- користувач повинен бути членом організації;
- лише `ADMIN` може видалити організацію;
- видалення виконується в одній транзакції;
- разом з організацією видаляються всі пов'язані дані.

---

## Що робить бекенд

1. Перевіряє авторизацію користувача.
2. Перевіряє наявність організації.
3. Перевіряє членство через `requireMembership()`.
4. Перевіряє роль користувача (`ADMIN`).
5. Запускає транзакцію.
6. Видаляє всі пов'язані записи.
7. Видаляє організацію.
8. Видаляє `Location`, якщо вона існує.
9. Повертає повідомлення про успішне видалення.

---

## Response

```json
{
  "status": "success",
  "code": "ORGANIZATION_DELETED",
  "message": "Organization and all related data were deleted",
  "data": {
    "result": {
      "message": "Organization and related data deleted successfully"
    }
  }
}
```

---

## Побічні ефекти

Після успішного виконання видаляються:

- Organization;
- Join Requests, пов'язані з організацією;
- UserOrganization (усі учасники);
- Host Profile;
- Tasks організації;
- Reviews, написані організацією;
- Reviews, залишені організації;
- Location (якщо вона існує).

Усі операції виконуються в межах однієї транзакції.
