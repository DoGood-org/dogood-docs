# GET /organization

## Призначення

Повертає список організацій, назва яких містить вказаний пошуковий рядок.

Endpoint використовується для пошуку організацій під час введення назви.

> [!NOTE]
>
> - Пошук виконується за полем `name`.
> - Пошук нечутливий до регістру (`case-insensitive`).
> - Повертаються лише основні дані організації.
> - Максимальна кількість результатів — **20**.

---

## Авторизація

❌ Не потрібна

Endpoint доступний без авторизації.

---

## Query Parameters

| Параметр | Тип    | Обов'язковий | Опис                                        |
| -------- | ------ | :----------: | ------------------------------------------- |
| name     | string |      ✔       | Назва або її частина для пошуку організацій |

### Приклад

```http
GET /organization?name=ama
```

---

## Business Rules

- параметр `name` є обов'язковим;
- пошук виконується за частковим збігом назви;
- пошук нечутливий до регістру;
- повертається не більше 20 організацій;
- якщо збігів немає — повертається порожній масив.

---

## Що робить бекенд

1. Перевіряє наявність параметра `name`.
2. Перевіряє, що `name` не є порожнім рядком.
3. Виконує пошук організацій за назвою.
4. Повертає знайдені організації.

Відсутні.
